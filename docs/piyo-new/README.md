# 店員ピヨちゃん 衣装パーツ (docs/piyo-new/)

うさぽんハロウィン街の店員ピヨちゃん用 3D衣装の完成版です。
**ゲーム本体(`index.html`)にはまだ組み込んでいません。** 見た目は作成者(吉田さん)確認済み(2026-10-10)。組み込みは別作業で行います。

## 中身
| 場所 | 内容 |
|---|---|
| `glb/` | 衣装パーツ10個(スキン済みGLB) |
| `base/piyo_base_rig.glb` | 素体(9ボーン)。衣装はこの骨に合わせて書き出し済み |
| `preview/` | 試着プレビュー画像(3店の全体図、各店の前/斜め/横/後ろ、帽子アップ) |
| `manifest.json` | パーツ一覧・ボーン割り当て・色指定・店ごとの組み合わせ(機械可読) |
| `fit_params.json` | 位置合わせに使った数値(調整をやり直すとき用) |

## 店ごとの組み合わせ
- **お花屋さん**: `apron_flower` + `scarf_felt`(緑) + `beret_felt`(緑) + `deco_flower`
- **CAFE**: `apron_cafe` + `scarf_felt`(茶) + `beret_felt`(茶) + `deco_cafe`
- **雑貨屋さん**: `apron_store` + `scarf_felt`(紫) + `hat_store`(紫。カチューシャ+シルクハットで一体) + `star_hat` + `star_scarf`

## 色(着色)
フェルトのパーツ(`beret_felt` / `scarf_felt` / `hat_store`)は灰色テクスチャで、ゲーム側で `material.color` に店の色を掛けます。飾り・エプロン・星は着色しません。

| 店 | RGB(0〜1) |
|---|---|
| お花屋さん(緑) | 0.59, 0.71, 0.52 |
| CAFE(茶) | 0.59, 0.33, 0.22 |
| 雑貨屋さん(紫) | 0.63, 0.40, 0.86 |

新しいお店を増やすときは、共通のベレー帽・スカーフに色を足し、飾りとエプロンを別パーツで足すだけで済む作りです。

## 技術メモ
- 全パーツ 素体と同じ9ボーン(`mixamorig:` 付き、名前は変更不可)・同じ逆バインド行列のスキンメッシュ。素体のスケルトンにそのまま束ねられます。
- ウェイト: 帽子・飾り・星(帽子側)は Head 100%、スカーフは Spine 中心(Head 少し)、エプロンは Spine+Hips に腕の付け根を少し。
- 影は頂点カラー(`COLOR_0`)に焼き込み済み。ゲームの `MeshBasicMaterial`(ライト無し)前提です。
- 1着あたり約0.75〜0.9MB・約1.1〜1.2万ポリゴン。JPEGテクスチャ(各256〜768px)。
- 確認済み: 試作ビューア(ゲームの `miniGLB` ローダーと同じ読み込み方、three.js r128)でのスキン表示と、首振り・腕上げ・傾きのポーズ。**他のGLBローダーでの検証や、スマホ実機での重さの確認はまだです。**
- 腕を大きく上げると、エプロンとスカーフが少しめり込みます(ウェイト調整の余地あり)。
- 素体と衣装は「骨に対する相対位置」で作ってあるので、素体を差し替えても骨の位置が同じなら使えます。
