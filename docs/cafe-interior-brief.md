# カフェの店内づくり 指示書(クラウド Claude Code 用)

## ゴール
うさぽんのハロウィン街(`usapon-machi`)の「カフェ(`shop:'cupcake'`)」に入れるようにして、店内を歩き回り、今あるカメラUIで写真が撮れるところまで作る。

- 今回やらない: 椅子に座る判定、メニューを見る操作、他のお店(お花屋さん・雑貨屋さんは別方式で後日)
- 参考画像: `docs/ref/cafe_interior.png`(あたたかい木の梁・アーチ窓・緑のドア・黒板メニューのカウンター・丸テーブルと椅子・吊りランプ・観葉植物)。この雰囲気に寄せる。そっくりでなくてよいが、色(木のブラウン、くすんだグリーン、クリーム壁、夕方のあたたかい光)は合わせる。

## 前提
- リポジトリは `usapon-machi`、単一の `index.html`(約7.4MB、three.js r128)。main の最新(ed345fb 以降)から `cafe-interior` ブランチを切って作業する。mainへは直接入れない。
- 他のチャットも main に変更を入れるので、作業の最初に必ず最新の main を確認すること。
- 店内のコードは `// ===== CAFE INTERIOR =====` のような目印で囲んだ一か所にまとめ、街の他の部分は最小限の接続だけにする(競合を防ぐため)。
- 既存のカフェ関連コード: `shopsOut`(`shop==='cupcake'`、ドア前の位置・向き)、`shopExtras`、1978行付近のカフェテラス、3468行付近の「おみせの中は じゅんびちゅう」トースト(これを入店処理に置き換える)。行番号はずれる可能性があるので検索して探すこと。

## 作ってほしいもの
1. 入店: カフェのドア前に近づくと入れる(ボタン or 自動)。画面を一瞬暗くして店内へ移動。店内は街とは離れた場所(別エリア)に作ってよい。
2. 店内の空間: 参考画像を3Dで再現。部屋の殻(床・壁・梁・アーチ窓・緑のドア)、カウンター(ガラスドーム・コーヒーマシン・黒板メニュー・棚と小瓶)、丸テーブルと椅子 3〜4組、スツール、吊りランプ 3つ、観葉植物、ラグ、額縁。
   - 小物は three.js の基本形(Box/Cylinder/Sphere など)で作る。Meshy 等のGLBは今回は使わない(重くしない)。
   - 黒板メニューは canvas テクスチャで描く(カップの絵と線で十分)。
   - 窓の外は、空の色と簡単な街並みシルエットでよい。
3. 光: 夕方のあたたかい雰囲気。吊りランプにグロー、暖色のポイントライト(多すぎない、2〜3個)、窓から差す光の雰囲気(ごく簡単でよい)。スマホで軽く動くことが最優先。
4. 移動: 既存のジョイスティック/操作で店内を歩ける。壁・カウンター・テーブルとの当たり判定は既存の `addBoxCol` / `addCircle` / `resolveXZ` の仕組みを使う。カメラは壁にめり込まないこと。
5. 退店: ドア付近で外に出られる。出たらカフェのドア前に戻る。
6. 写真: 店内でも既存の写真ボタン・カメラモード(ピヨちゃん目線/自撮り)・アルバム保存が動く。UIの文言は日本語、ひらがな多めのやさしい口調(既存に合わせる)。
7. 他への影響なし: 店内にいる間は街のおばけ・パネル判定やミニマップが変な表示にならないようにする(店内ではミニマップ非表示、またはカフェの場所に固定でよい)。

## 動作確認のしかた
- クラウドでは CDN がブロックされることがある。`npm install three@0.128.0` でローカルに置き、Playwright(Chromium、`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`)でスクリーンショットを撮って見た目を確認すること。
- 最低限 `node --check`(スクリプト部分)を通すこと。
- 画面確認ができたら、数枚のスクリーンショット(ドア付近・カウンター・テーブル席・窓際)を提出して、うさぽん(依頼主)にスマホでの見た目確認をしてもらう。

## 提出
- `cafe-interior` ブランチにプッシュし、変更の要点(追加した関数、既存コードに触れた箇所)を日本語で短くまとめる。
- main への取り込みは、依頼主の確認後にうーちゃん(Codex)が行う。

## 守ること
- 返信・コメントは日本語、簡潔に。
- 強制プッシュ、他ブランチの削除、課金設定の変更はしない。
- 重くなりそうな案(大量の影、高解像度テクスチャ、巨大なGLB)は、やる前に相談する。
