# 2026年版：魔法のスティック（ローカル確認版）

起点: `origin/main` の `24e0125`。2026-10-22に実装。未公開・未コミット。
対象: `2026/index.html` と `2026/magic.js`。ルートの街版・2025年版は変更しない。

## 遊び方（2026-10-23 UI統合）

1. パネルイベント開放後、既存の「パネル→ほうき→時計塔の宝箱」で杖を入手する。
2. 右下の丸い杖ボタンで装備／解除。装備中だけ杖を持ち、魔法アクションを表示する。
3. 小物を直接タップして浮かせ、左の移動スティックで運ぶ。持っている間だけ回転・設置・キャンセルの丸ボタンを表示する。
4. 星のボタンはキラキラ、放射状のボタンは花火。杖を振り、小さな光が先端を追う。
5. 杖を装備して既存のカメラを開くと9:16。既存シャッターで直前に選んだ魔法を添えて撮影する。撮影モードでは魔法操作を隠す。
6. 出力は1080×1920 JPEG。既存のアルバム／ダウンロードを利用する。カメラ終了で通常の撮影比率に戻る。
7. ひとつ戻す・元の配置に戻すは、歯車内の「まほうのスティック」へ整理。元の配置は確認後に実行する。

中央の操作パネルと「えらぶ」ボタンは廃止。短い初回案内をブラウザごとに一度表示する。

## 遊びやすさ調整（2026-10-23 Claude）

- 動かせる物の表示: 杖を装備している間だけ、近くの動かせる小物（最大8個）の足元に淡い輪、上に小さな星を出す。手の届く範囲（8m）は少し濃く、その外は薄い。
- 対象の追加: タル（barrel）・かぼちゃ箱（crate、花だんの一部でない単独のもの）。当たり判定が1つだけ・席/パネル/街灯コード/IDなし・足元半径1m以下の物に限定。ベンチ・花だん・パネル・宝箱・進行アイテムは固定のまま。
- 置ける条件の整理: 小物の実際の大きさで判定（以前は一律0.65m扱い）。道の上にも置ける（2026-10-23 本人確認：ふさがってもジャンプや動かし直しで対応できるため）。階段は+0.5m、お店の入口は+1.8m、他の物とは+0.08m。元の場所から8m以内（以前6m）。進行アイテム・パネル等の近くは引き続き不可。
- 控えめな吸着: 正面の位置が置けなくても、0.9m以内に空きがあればそこを緑の輪で示す。近くに無いときは3.5m以内の置ける場所を小さな緑の輪で示す。
- 村の端（2026-10-23 確認後の調整）: 以前は中心から38mで「村の外」扱いだったため、南の入口の門の手前で置けなかった。ピヨちゃんが歩ける範囲（±40m）から小物の半径を引いた所までに合わせ、持っている小物の位置もその内側で止まる。
- 壁の向こうを案内しない（Solレビュー）: 置き場所・吸着先・案内の輪は、ピヨちゃんから一直線に行ける場所だけ。途中に壁・建物・他の物の当たり判定や0.45m以上の段差があれば「✕ かべの向こうには置けないよ」。
- 運ぶ位置: ピヨちゃんの右前（杖の手側）に浮かせ、後ろからのカメラでも見えるようにした。
- 理由表示: 輪の下に「◯ ここに置けるよ」「✕ 建物やかべに近いよ」「✕ ほかの物に近いよ」「✕ お店の入口に近いよ」「✕ 階段の近くは置けないよ」「✕ ななめの所は置けないよ」「✕ 元の場所から遠いよ」など。色と記号の両方で示し、丸ボタンに重なる時は輪の上に出す。持ち運び中の輪は草や物に隠れないよう最前面に描く。✓ボタンは置けない時も押せて、押すと理由を出す。
- タップの反応: 杖装備中のタップには必ず波紋と短い吹き出しを返す（「もう少し近づいてね」「これは動かせないよ」「光っている小物をタップしてね」「近くに動かせる小物がないよ」「置くときは ✓ ボタンだよ」）。小さな物は指が少しずれても（約38px）選べるが、その物自体が最初に見えている場合だけ（壁越しには選ばない）。
- 杖の動き: ピヨちゃんのリグには手のボーンが無いため、右腕の先で杖を持つ。装備中は右腕を少し上げて杖を上向きに保持（歩行の揺れを少し残す）。キラキラ／花火では「振り上げ→前へ振る→戻す」の動きと先端の光の軌跡。運ぶ間は杖先を小物へ向け、小さな光が小物へ流れる。杖の光は控えめに縮小（宝箱の杖本体の素材は変更しない）。腕の姿勢は毎フレーム歩行ポーズの上に重ねるだけで保存しないため、歩行・着席・飛行・自撮り・解除時の姿勢は変わらない。

## 魔法の演出（2026-10-23 本人依頼）

- 振る: キラキラ・花火のボタンで、ピヨちゃんの頭の上に金色の光のリボンが右から左へ弧を描く（約0.32秒）。リボンの各点は約0.3秒でふわっと消え、杖先はリボンの先頭を追う。終点で小さな星がキラキラ。
- 発動: リボンの終点で光の輪が二重に「ポンッ」と広がる（約0.4秒）。キラキラの魔法は正面約3mにも輪と星。
- 花火: リボンの終点から光が約0.6秒で上昇し、五角の星形に開く。星の点はゆっくり広がって止まり、細かいキラキラがゆっくり落ちて約2.5秒で消える。星の色は金・ピンク・ミント・ラベンダーのどれか＋金。
- 実装は magic.js 内の小さな専用プール（星の粒260個のPoints1つ、リボン1メッシュ、輪は一時メッシュ）。ゲーム共有の火花プールはほぼ使わない。撮影時の演出はカメラの「✨エフェクト」（2026/cam-effects.js）が決め、花火は magic.js の `fx:{firework,pop,twinkle}` を使う。星の粒は描画時に実際の画面サイズから大きさを決めるので、1080×1920の写真でも画面と同じ見え方。

## 範囲と保護

- `EVENT.panels=false` は変更していない。パネルイベントの公開・素材追加は別作業。
- 既存の小物を利用し、新しいワールドやモデル、外部API、有料サービスは追加しない。
- 対象種別は pumpkin / pot / lantern / bucket / barrel / crate。大きすぎる小物、非表示・予備小物、当たり判定が複数ある物は除外。
- 元の配置から8ワールド単位以内、ほぼ同じ高さの平坦な地面に限る。階段・店舗入口・他の当たり判定・進行用アイテムを避ける（道の上は可）。建物／進行用アイテムは移動不可。
- 持ち運び中は見た目だけ浮かせ、当たり判定は最後に確定した位置に残す。室内・泉・飛行・着席・別の配置モードでは魔法を停止し、持ち物を戻す。
- 配置保存先は `usapon-halloween-2026-magic-layout-v1`。共有の進行キーと制作側の編集下書きには書き込まない。
- 保存失敗時は配置と戻す履歴を巻き戻す。復元時は形式・有限値・対象ID・配置場所を検証する。
- 既存の進行・アルバム自体は街版と共通名のまま。この変更では既存データ移行をしない。
- 演出は既存420粒のプールを共有し、1.4秒の連発制限。移動小物の距離カリングは現在位置に追従。

## ローカル確認

この作業フォルダをルートに `python3 -m http.server 4186 --bind 127.0.0.1`。

- 通常: http://127.0.0.1:4186/2026/
- 杖の確認: http://127.0.0.1:4186/2026/?magic-preview=1

確認用クエリは localhost / 127.0.0.1 / [::1] のみ有効。メモリ上で杖取得済みにする。イベント設定は変えない。通常のゲーム操作で進行が保存される場合、ローカル確認用の取得状態もそのローカルオリジンに保存される。公開サイトの進行とは別。

## 検証

Playwright と Chrome が必要。インストール済みPlaywrightの場所を `PLAYWRIGHT_MODULE` で指定可能。

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node tests/halloween-magic-smoke.cjs
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node tests/halloween-magic-edge.cjs
```

`GAME_URL` でローカル確認先を変更可能。テストは新規ブラウザコンテキストのみを使用する。edgeテストはHTML応答をテスト内だけでパネル有効に差し替え、宝箱取得ルートを検証する。
